# TODO App

LocalStorageを使ったシンプルなTODOアプリです。

**Demo:** https://araki-m.github.io/todo2/

## 機能

- **TODO管理** — 追加・完了・削除。各TODOにNo.を自動採番
- **カテゴリ** — 仕事 / プライベート / その他 から選択
- **登録日付** — 追加時に自動記録
- **締め切り日** — 任意で設定可能。締切2日以内の未完了TODOは赤枠で警告表示
- **フィルター** — ステータス（すべて/未完了/完了）とカテゴリの組み合わせ絞り込み
- **並び替え** — ドラッグ＆ドロップでタスクの順番を自由に変更可能
- **ステータスバー** — 完了・未完了の件数と進捗を棒グラフで表示
- **分析タブ** — 概要、カテゴリ別完了率、締切状況、完了数の時系列グラフ（全体+カテゴリ別）をダッシュボード表示
- **データ永続化** — LocalStorageに自動保存。リロードしても復元

## 技術構成

- HTML / CSS / JavaScript（Vanilla JS）
- フレームワーク・ビルドツール不要
- `index.html` 1ファイルで完結

## 使い方

ブラウザで `index.html` を開くだけで動作します。

```
git clone https://github.com/araki-m/todo2.git
open todo2/index.html
```
